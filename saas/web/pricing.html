Why piilex?

50+ PII Types

Detects email, phone, SSN, credit card, My Number (Japan), IBAN, biometric data, and 40+ more types across all major languages.

Data Flow Tracing

Tracks PII from input to output: logs, databases, APIs, HTTP responses. Cross-file import/export tracking included.

Regulatory Mapping

Maps each finding to specific GDPR articles, CCPA sections, and APPI provisions. Article-by-article compliance reports for auditors.

CI/CD Ready

SARIF output for GitHub Code Scanning. --fail-on exit codes. GitHub Action available. Baseline diff shows only new issues.

Fast

Built in Rust with tree-sitter AST parsing. 4.6MB binary. Scans thousands of files in seconds.

VS Code Extension

Real-time PII detection with inline warnings and quick-fix code actions as you type.
